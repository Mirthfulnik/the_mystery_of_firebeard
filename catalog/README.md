# Улика — каталог детективных игр для вечеринок

Статический сайт (GitHub Pages). Оценки, просмотры, репосты и комментарии хранятся в Supabase.
Пока Supabase не подключён, сайт работает в демо-режиме: всё сохраняется только в браузере.

Адрес после публикации: `https://<логин>.github.io/the_mystery_of_firebeard/catalog/`

## 1. Подключить базу (Supabase, бесплатно)
1. Зарегистрируйтесь на supabase.com → New project.
2. SQL Editor → New query → вставьте содержимое `supabase.sql` → Run.
3. Project Settings → API: скопируйте **Project URL** и ключ **anon public**.
4. Впишите их в `config.js` (`supabaseUrl`, `supabaseAnonKey`) и закоммитьте.
   Ключ anon публичный по замыслу: прямой доступ к таблицам закрыт, писать можно только через функции.

Скрыть комментарий: в SQL Editor выполнить `update public.comments set hidden = true where id = 123;`

## 2. Реклама
Три места: шапка, левая колонка (только на широком экране), низ экрана (можно закрыть).
- **Рекламная сеть Яндекса**: partner.yandex.ru → создайте 3 блока RTB → ID вида `R-A-1234567-1`
  впишите в `config.js` → `ads.yandex.top / left / bottom`.
- **Google AdSense**: `ads.google.client` = `ca-pub-…`, а в `top / left / bottom` — ID слотов.
  Для AdSense положите в корень сайта файл `ads.txt` со строкой из кабинета.
- Если заданы обе сети, показывается та, что в `ads.prefer`.
- `placeholders: false` — скрыть пустые рамки «Место для рекламы».

## 3. Добавить игру
Допишите объект в массив `GAMES` в `js/data.js` (по образцу «Призрака Огнеборода»),
картинки положите в `media/`: постер 600×900, обложка 1280×720, скриншоты 1600×900 + миниатюры.

## Экраны
Телефон, ноутбук, телевизор. На ТВ включается крупный режим (кнопка «ТВ» в шапке),
навигация стрелками пульта.
