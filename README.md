# Призрак Огнеборода

Хэллоуинский детектив для компании из 3–5 человек. Экран игры открывается на телевизоре, ноутбуке или планшете, а игроки подключаются телефонами по QR-коду. Сервер не нужен: сайт публикуется на GitHub Pages бесплатно.

> Не открывайте `js/content.js` до игры — там разгадка.

## Как опубликовать на GitHub Pages

1. Зайдите на [github.com](https://github.com) и создайте новый репозиторий: **New repository**. Назовите, например, `ognebord`. Видимость — **Public** (на бесплатном аккаунте Pages работает только с публичными репозиториями).
2. На странице репозитория нажмите **Add file → Upload files**. Перетащите в окно **всё содержимое** этой папки (файлы `index.html`, `play.html` и папки `css`, `js`, `img`, `fonts`, `vendor`, `audio`). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**. Нажмите **Save**.
4. Через 1–2 минуты сверху появится адрес вида `https://ваш-логин.github.io/ognebord/`. Это и есть игра.

## Как играть

1. Откройте адрес игры на телевизоре или ноутбуке, подключённом к телевизору. Выберите число игроков и нажмите **Новая игра**.
2. Игроки наводят камеру телефона на QR-код и вводят имя. Когда все на борту, нажмите **Раздать роли**: роли раздаются случайно.
3. Дальше листайте игру кнопкой **Далее** (или стрелкой →, пробелом). Первый подключившийся телефон получает кнопку **Пульт**: с него тоже можно листать.

Ход партии: знакомство с персонажами → пролог → осмотр места преступления → 5 раундов (вступление, рассказы, обсуждение) → полночь → голосование → разгадка и очки. Партия идёт 1,5–2 часа.

### Управление на экране ведущего

| Клавиша | Действие |
| --- | --- |
| → или пробел | Далее |
| ← | Назад |
| P | Пауза таймера |
| M | Выключить звук |
| F | Во весь экран |
| Esc | Закрыть открытую улику |

Улики, которые игроки раскрыли решениями, остаются на экране внизу слева. Нажмите на любую, чтобы показать её снова.

### Если что-то пошло не так

- **Телефон не подключается.** Телевизор и телефоны должны быть в интернете, лучше в одной сети Wi‑Fi. Связь идёт напрямую между устройствами через бесплатный сервер PeerJS, поэтому на мобильном интернете с некоторыми операторами подключения может не быть.
- **Телефон выключился или закрылась вкладка.** Откройте ту же ссылку снова: игрок вернётся на своё место с теми же карточками.
- **Игрок сменил телефон.** Откройте ссылку на новом телефоне и нажмите «Я — имя».
- **Перезагрузился экран ведущего.** Откройте адрес игры снова и нажмите **Продолжить игру**. Код комнаты сохранится, телефоны переподключатся сами (иногда через 10–30 секунд).
- **Нет звука.** Браузеры включают звук только после нажатия кнопки. Нажмите любую кнопку на экране ведущего.

## Музыка и звуки

Вся музыка и эффекты генерируются прямо в браузере, файлы не нужны. Чтобы заменить любой звук своим:

1. Положите файл в папку `audio` с именем по ID из ТЗ: например `MU-01.mp3` (музыка на титуле) или `SFX-01.mp3` (хохот призрака).
2. Впишите имя файла в `audio/files.json`: `["MU-01.mp3", "SFX-01.mp3"]`.

| ID | Где звучит |
| --- | --- |
| MU-01 | Титул, лобби, итоги |
| MU-02 | Пролог, вступления раундов, эпилог |
| MU-03 | Осмотр и чтение карточек |
| MU-04 | Обсуждения |
| MU-05 | Раунд 3, шоу призрака |
| MU-06 | Полночь |
| MU-07 | Голосование |
| MU-08 | Дело раскрыто |
| MU-09 | Дело не раскрыто |
| SFX-01…SFX-22 | Эффекты по списку из ТЗ на звук |

## Для разработчика

- `js/content.js` — все тексты сценария, зоны осмотра, решения, таймеры.
- `js/game.js` — правила: шаги, решения, голосование, подсчёт очков.
- `js/host.js`, `js/player.js` — экраны ведущего и игрока.
- `js/net.js` — связь через PeerJS. Параметр `?peer=host:port` в адресе подключает свой сервер PeerJS вместо публичного.
- `js/audio.js` — синтезатор музыки и звуков.

Таймеры по умолчанию: осмотр 5 минут, обсуждение 7 минут, полночь 10 минут, голосование 3 минуты. Меняются в конце `js/content.js` (в секундах). Кнопка «+1 мин» добавляет время по ходу игры.
