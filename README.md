# Призрак Огнеборода

Хэллоуинский детектив для 1–5 игроков и ведущего. Экран игры открывается на телевизоре, ноутбуке или планшете. Игроки подключаются телефонами по QR-коду или по ссылке — из любой сети, хоть из другого города. Сервер не нужен: сайт работает на GitHub Pages.

> Не открывайте `js/content.js` до игры — там разгадка.

## Опубликовать на GitHub Pages

1. Загрузите все файлы этой папки в репозиторий (вместе с папками).
2. **Settings → Pages → Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
3. Через 1–2 минуты игра откроется по адресу `https://логин.github.io/имя-репозитория/`.

## Как играть

1. Откройте адрес игры на телевизоре и нажмите **Новая игра**.
2. **Ведущий** сканирует маленький QR-код «для ведущего» справа. На его телефоне — пульт (Далее / Назад, таймер, рассказчики), весь текст текущего шага и карточки персонажей, которых играет он сам.
3. **Игроки** сканируют большой QR-код в спасательном круге и вводят имя. Ведущий может отправить ссылку в мессенджер кнопкой «Отправить ссылку игрокам» — подключиться можно из другой сети.
4. Ведущий нажимает **Раздать роли**. В игре всегда все пять персонажей: игрокам сначала достаются главные роли (дворецкий, капитан, кок), остальных читает и разыгрывает ведущий — их карточки и решения у него на телефоне во вкладке «Роли ведущего».
5. Дальше ведущий листает игру со своего телефона. Если телефона ведущего нет, листать можно на самом экране: кнопка **Далее**, стрелка → или пробел.

На экране слева — сцена целиком, справа — весь текст шага. У игроков на телефоне вкладки: **Карточка**, **Осмотр** (место преступления), **Пометки** (личный блокнот) и **Роль**.

Ход партии: знакомство → пролог → осмотр места преступления → 5 раундов (вступление, рассказы, обсуждение) → полночь → голосование → разгадка и очки. 1,5–2 часа.

### Клавиши на экране ТВ

| Клавиша | Действие |
| --- | --- |
| → или пробел | Далее |
| ← | Назад |
| P | Пауза таймера |
| M | Выключить звук |
| F | Во весь экран |
| Esc | Закрыть открытую улику |

### Если что-то пошло не так

- **Телефон не подключается.** Нужен интернет на ТВ и телефонах. Сеть может быть любой — связь идёт через бесплатный публичный сервер сообщений, все сообщения зашифрованы ключом из QR-кода.
- **Телефон выключился или закрылась вкладка.** Откройте ту же ссылку снова — игрок вернётся на своё место. Пометки сохраняются в телефоне.
- **Игрок сменил телефон.** Откройте ссылку на новом телефоне и нажмите «Я — имя» (появится через 15 секунд после отключения старого).
- **Перезагрузился экран ТВ.** Откройте адрес игры и нажмите **Продолжить игру**. Телефоны переподключатся сами.
- **Нет звука.** Нажмите любую кнопку на экране ТВ: браузеры включают звук только после нажатия.

## Музыка и звуки

Музыка и эффекты генерируются в браузере. Чтобы заменить любой звук своим, положите файл в папку `audio` с именем по ID (например `MU-01.mp3`, `SFX-01.mp3`) и впишите имя в `audio/files.json`: `["MU-01.mp3"]`.

| ID | Где звучит |
| --- | --- |
| MU-01 | Титул, лобби, итоги |
| MU-02 | Пролог, вступления, эпилог |
| MU-03 | Осмотр и чтение карточек |
| MU-04 | Обсуждения |
| MU-05 | Раунд 3, шоу призрака |
| MU-06 | Полночь |
| MU-07 | Голосование |
| MU-08 / MU-09 | Дело раскрыто / не раскрыто |
| SFX-01…SFX-22 | Эффекты по списку из ТЗ на звук |

## Для разработчика

- `js/content.js` — тексты сценария, зоны осмотра, решения, таймеры (в секундах, в конце файла).
- `js/game.js` — правила: шаги, роли, решения, голосование, очки, текст каждого шага.
- `index.html` + `js/host.js` — экран ТВ, `play.html` + `js/player.js` — игрок, `gm.html` + `js/gm.js` — ведущий.
- `js/net.js` — связь через MQTT поверх WebSocket (брокеры broker.emqx.io, broker.hivemq.com, test.mosquitto.org; экран выбирает первый доступный). Параметр `?broker=ws://адрес:порт` подключает свой брокер.
- `js/audio.js` — синтезатор музыки и звуков.

## Установка как приложение (PWA)
В каталоге (главная и страница игры) есть кнопка «Установить на ПК» — Chrome, Edge, Яндекс Браузер:
ярлык на рабочем столе, отдельное окно, картинки и код хранятся на устройстве.
После любых изменений в файлах игры пересоберите список кэша: `python3 tools/build_sw.py`
(иначе установленные копии не узнают о новых картинках).
